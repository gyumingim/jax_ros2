JAX 팔 실행 지도

jax_ros2 의 파이썬 파일이 많아 보이지만, 사람이 직접 실행하는 건 몇 개뿐이고 나머지는 그것들이 불러 쓰는 부품이다. 기준: 포크 gyumingim/jax_ros2 의 dashboard-homing 브랜치 (2026-11-20).

평소엔 python3 dashboard/server.py 하나만 켠다. 브라우저에서 http://localhost:8080 (이 PC는 8080 이 막혀 8096). 아래 1~4 단계를 전부 버튼으로 할 수 있다.

실행 순서 (실물 팔)

  1. CAN 켜기 — 재부팅마다 1번
    sudo ip link set can0 up type can bitrate 1000000
    대시보드: 연결 탭 → can0 올리기
  2. 노드 4개 한 번에 켜기
    ros2 launch arm_control arm_homed.launch.py
    • ak45_node C++ AK45 4개 ↔ CAN
    • stm_bridge_node.py 서보 서보 10개 → CAN → STM32
    • homing_guard.py AK 원점 없으면 AK 명령을 막음
    • arm_control_node.py 시뮬 관절각 → 모터각 변환 + 30°/s 램프
  3. 원점 잡기
    관절을 기준 자세(시뮬 0°)에 두고 대시보드 각도 제어 탭 → 원점 잡기. 켤 때마다·전원 재투입마다·쉬게 한 뒤마다 다시.
  4. 쓰기 — 필요한 것만
    • 각도 제어: 슬라이더 → 보내기 (대시보드)
    • vision_node.py: 큐브 위치 → /object_pose
    • pick_place.py: 큐브 집어 옮기기 (계획 → 검사 → 재생). 대시보드는 --dry-run 만

명령이 흘러가는 길

주황 점선 = AK45 위치 피드백. 원점 guard 가 오프셋을 빼서 arm_control 에 넘긴다. arm.launch.py(guard 없는 옛 방식)는 guard 칸이 빠지고 arm_control 이 ak45_node 와 바로 붙는다.

상황별로 켜는 것

평소 사용

  • can0 → arm_homed.launch.py
  • 원점 잡기
  • 각도 제어 또는 pick_place

보정 (방향·영점 재기)

  • ak45_node + stm_bridge_node 만
  • 터미널: ros2 run arm_control calibrate --ros
  • arm_control·launch 는 꺼 둔다 (같은 모터를 둘이 명령)

실물 없이 가상

  • python dashboard/server.py --virtual
  • virtual_arm 이 calibration·motion·homing 을 그대로 써서 흉내
  • Windows 에서도 동작
