JAX 팔 실행 지도

내 포크 gyumingim/jax_ros2 의 noros 브랜치 기준 (2026-11-20). ROS 없이 대시보드 하나가 CAN 을 직접 연다.

켜는 건 python3 dashboard/server.py 하나뿐.
브라우저 http://localhost:8080 · ROS·colcon 필요 없음 · 실물 없이 시험은 --virtual

실행 순서 (실물)

  1. 설치 (한 번)
    sudo apt install can-utils python3-can python3-fastapi python3-uvicorn python3-websockets
  2. 대시보드 켜기
    python3 dashboard/server.py
    위쪽 스위치 = 실물
  3. 연결 탭: ① CAN 켜기 → ② 팔 연결
    팔 연결 = real_arm.py 가 can0 을 열고 AK45 4개 피드백을 받기 시작. 이때는 아직 아무 명령도 안 보낸다.
  4. 보정 확인 (처음 한 번)
    팔을 받치고, 연결 탭 고급 → 관절 하나씩 보정 → 관절마다 +2° 로 방향 확인 후 저장.
  5. 각도 제어 탭: 원점 잡기 → 움직이기
    기준 자세(팔 수직으로 내림)에서 [전부 원점 잡기]. 그 순간 AK45 가 힘을 준다. 처음엔 한 관절 2~5°.
  6. 역기구학 탭 (필요하면)
    지도에서 큐브 → 놓을 자리 클릭 → [계획 돌려 보기]. 실물 재생은 보정을 다 확인한 뒤.

명령이 흘러가는 길

주황 점선 = AK45 위치 피드백. 서보는 피드백이 없어 "마지막으로 보낸 값"만 안다.

파일 역할

파일하는 일
dashboard/server.py웹 서버. 이것만 실행한다.
dashboard/real_arm.py실물 직접 제어 AK서보 — 안전 로직 전부
dashboard/virtual_arm.py가상 팔 가상 — 같은 규칙으로 흉내
dashboard/direct_api.py화면 버튼 → real_arm (연결·홀드·힘 빼기·보정·재생)
dashboard/reachmap.py역기구학 지도(IK 레포의 도달 맵)
dashboard/static/*화면 (app.js, direct.js, viewer.js 3D)
arm_control/*.py부품으로 가져다 씀: calibration(각도 변환), motion(램프), homing(원점), play·watch(궤적 재생·감시), protocol(AK45 프레임). calibration.json, homing.json
stm_bridge/protocol.py부품: 서보 CAN 프레임
dashboard/tools/가짜 하드웨어 시험(try_direct_fake.py), Windows 재시작 스크립트
ak45_ros2/ 등팀 ROS 버전 — server.py --ros 일 때만. 평소엔 안 씀 (ROS_TEAM.md)

평소

  • server.py → 실물
  • ① CAN ② 팔 연결
  • 원점 → 각도 제어 / 역기구학

실물 없이 가상

  • server.py --virtual
  • Windows 에서도 됨

멈추기

  • STOP(Esc) = 그 자리 홀드, 팔 안 떨어짐
  • 힘 빼기 = 브레이크, 팔 떨어짐 (받치고)

아직 미확인

  • 실물 can0 에서 한 번도 안 돌림
  • 보정 전부 가정, 손목 서보 방향
